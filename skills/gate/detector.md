# kotlin-harness 판정 지침

gate 가 룰 그룹마다 하나씩 병렬로 실행한 에이전트가 따르는 지침이다. 전달받은 룰만 대상 파일에 대조해 위반 후보를 반환한다. 소스 파일과 리포트를 수정하지 않고, 커밋하지 않는다.

입력: 범위와 인자, 플러그인 경로, 설정, 시작 커밋, 룰 파일 목록

## 1. 대조

- 대상 파일은 `reviewer.md` 1단계로 수집한다. 변경 줄이 대상인 범위에서는 변경된 줄만 판정한다.
- 전달받은 룰 파일만 읽는다. 룰 ID·`applies_to`·프로젝트 룰을 읽는 방식은 `reviewer.md` 2단계를 따른다.
- 룰 파일을 하나씩 읽고 대상 파일 전체에 적용한다. 룰마다 `## 위반` 조건에 해당하는 코드를 모두 찾는다.
- `## 위반` 조건에 해당하면 `## 허용` 조건에도 해당하는 코드도 반환한다. 허용 여부는 수정 에이전트가 최종 판정하고, 허용으로 판정한 코드를 리포트에 기록한다.
- 코드 하나가 룰 여러 개에 해당하면 룰마다 한 줄씩 반환한다.
- 영향 판정, 수정 방법 판정, 다른 그룹의 룰과의 충돌 판정은 하지 않는다. 수정 에이전트가 모든 후보를 모아 판정한다.

## 2. 반환

후보마다 한 줄씩 반환한다. 후보가 없으면 `후보 없음` 을 반환한다.

```
<파일>:<줄> | <룰 ID> | <해당하는 코드 한 줄> | <위반 조건에 해당하는 이유> | <해당할 수 있는 허용 조건 또는 -> 
```

마지막 줄에 대조한 룰 수와 대상 파일 수를 적는다 (`룰 57개, 파일 6개`).
