# kotlin-harness 이슈 등록

인자: `$ARGUMENTS` (문제 설명. 비어 있으면 대화 내용과 최근 리포트로 판단한다)

## 1. 정보 수집

- 리포 주소: `${CLAUDE_PLUGIN_ROOT}/.claude-plugin/plugin.json` 의 `repository` 에서 `<owner>/<repo>` 를 추출한다.
- 플러그인 버전: 같은 파일의 `version`
- Claude Code 버전: `claude --version`
- 리포트: 인자나 대화에 리포트 경로가 있으면 그 파일, 없으면 `.claude/kotlin-harness/reports/` 에서 가장 최근 파일. 없으면 리포트 없이 진행한다.
- 문제가 된 항목: 인자와 대화에서 룰 ID, 위치, 처리 결과를 확인한다. 특정할 수 없으면 사용자에게 어떤 항목인지 묻는다.
- 룰 ID 가 `project/` 로 시작하면 그 프로젝트의 룰이므로 등록하지 않는다. 이슈에 프로젝트 규칙이 공개되기 때문이다. 프로젝트 룰 파일을 직접 수정하라고 안내하고 중단한다. 단, 프로젝트 룰을 읽거나 적용하는 스킬 동작(ID 부여, 충돌 처리 등)이 설명과 다르면 `스킬 동작` 으로 등록하고, 룰 내용은 옮기지 않는다.

## 2. 유형 분류

| 유형 | 기준 | 라벨 |
|---|---|---|
| 오탐 | 위반이 아닌 코드를 위반으로 보고했다 | `bug` |
| 누락 | 룰에 해당하는 코드를 보고하지 않았다 | `bug` |
| 잘못된 수정 | 수정한 코드가 틀렸거나, 동작이 바뀌었거나, 컴파일되지 않는다 | `bug` |
| 스킬 동작 | 리포트·커밋·설정 처리가 설명과 다르다 | `bug` |
| 룰 제안 | 새 룰, 룰 조건 변경, severity 변경 | `enhancement` |

## 3. 초안 작성

제목: `[유형] <룰 ID 또는 스킬 단계>: <한 줄 요약>` (예: `[오탐] common/null-safety/not-null-assertion: 직전 널 체크가 있는 !! 를 위반으로 보고`)

본문:

````markdown
## 요약
무엇이 기대와 달랐는지 한두 문장

## 룰
- 룰 ID: `common/null-safety/not-null-assertion` (스킬 동작 문제면 `-`)
- 처리 결과: 리포트에 적힌 처리 (`수정함 (커밋 …)` 등)

## 재현 코드
```kotlin
// 문제를 재현하는 최소 코드
```

## 기대 동작 / 실제 동작
- 기대:
- 실제:

## 리포트 발췌
리포트에서 해당 항목만 옮긴다. 코드 블록은 위 재현 코드로 대체한다.

## 환경
- kotlin-harness: 0.4.0
- Claude Code: 2.x.x
- platform: android (자동 판정) / 범위: branch / autoFix: true
````

### 프로젝트 정보 보호

플러그인 리포는 공개 리포이므로 이슈를 누구나 볼 수 있다. 사용자 프로젝트의 코드를 그대로 옮기지 않는다.

- 재현 코드는 문제를 재현하는 최소 코드로 다시 작성한다. 패키지명, 클래스·함수·변수 이름, 문자열 리터럴, URL, 도메인 용어는 `Foo`·`Repository`·`"value"` 같은 일반적인 이름으로 바꾼다.
- 키·토큰·계정·내부 주소처럼 보이는 값은 포함하지 않는다.
- 파일 경로는 `app/src/main/java/.../Foo.kt` 처럼 모듈과 파일 이름만 남긴다.
- 커밋 해시, 커밋 메시지, 브랜치 이름은 포함하지 않는다.
- gate 에 전달한 맥락(세션 요약, 힌트로 읽은 이슈·문서 내용)은 포함하지 않는다. 사내 정보가 들어 있을 수 있다.

## 4. 확인

초안(제목, 라벨, 본문)을 그대로 출력하고, 등록할지 사용자에게 묻는다. 사용자가 수정을 요청하면 초안을 고쳐 다시 묻는다. 사용자가 등록하라고 답하기 전에는 등록하지 않는다.

## 5. 등록

```
gh issue create --repo <owner>/<repo> --title "<제목>" --label <라벨> --body-file <본문 파일>
```

- 본문 파일은 임시 디렉터리에 작성하고, 등록 후 삭제한다.
- 등록한 이슈 URL 을 출력한다.
- `gh` 가 없거나 인증되지 않았으면 등록하지 않는다. 초안과 `https://github.com/<owner>/<repo>/issues/new` 주소를 출력하고, 직접 등록하도록 안내한다.
